# 术语速查

先用这些定义理解文档中的常见词。它们帮助区分创作概念，不是参数清单。

## 节点与连接

| 术语 | 含义 |
| --- | --- |
| 节点 | 承担发射、外观、运动或输出等职责的单元 |
| 端口 | 节点接收或提供某类内容的接口 |
| 连线 | 节点之间的关系，不是粒子的运动轨迹 |
| 分支 | 图中一条参与组合的流程路径 |
| Output | 最终汇集点，不是视频导出按钮 |

## 粒子与时间

| 术语 | 含义 |
| --- | --- |
| 发射 | 产生粒子的过程 |
| 寿命 | 一个粒子从出生到结束的持续时间 |
| 年龄 | 一个粒子从出生起已经经历的时间 |
| Over Life | 相对于单个粒子生命进度的变化 |
| 合成时间 | AE 当前所在的时间，与每个粒子的年龄不同 |
| 种子 | 用于确定随机结果的一项设置 |

## 外观与复用

纹理提供图像内容，模型提供几何形体，材质描述基础表面表现。预设是可复用的节点设置，工程则保留完整项目上下文；二者都不应被理解为已经渲染的视频。
