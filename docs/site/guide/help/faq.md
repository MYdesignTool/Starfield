# 常见问题

这里先回答与基本工作方式有关的问题。具体安装、按钮位置和参数截图会随发布版本补充。

## 必须会编程吗？

不需要。基本创作依靠节点连接、AE 效果控件和预设。你需要了解一些 AE 基础概念，见[使用前的准备](/start/requirements)。

## 官网演示会生成粒子吗？

不会。网页画布只提供节点 UI 体验；实际粒子结果需要在 AE 插件中查看。首页主视觉也不是一个可以直接应用的预设。

## 为什么节点里没有所有参数？

画布负责结构，参数在 AE 效果控件中编辑。不要为了找参数而一直放大节点，参见[AE 效果控件](/interface/effect-controls)。

## 移动节点为什么没有移动画面？

画布位置用于整理布局。想改变粒子位置，应调整相应节点参数；系统变换与节点布局不是同一件事。

## 已有 Emitter，为什么还要 Particle？

Emitter 负责发射，Particle 定义粒子生命和外观。基础流程是 Emitter → Particle → Output。

## 预设能代替工程备份吗？

不能。预设用于复用节点设置，工程和引用素材仍需单独保留，见[保存自己的预设](/presets/save)。
