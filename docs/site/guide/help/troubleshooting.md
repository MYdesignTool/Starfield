# 遇到问题时

先确认现象，再逐步缩小范围。保留当前工程副本，比同时修改许多设置更有助于排查。

## 面板没有显示

先确认使用的是匹配的插件版本和 AE 环境，并查看发布说明。不要根据其他版本的截图随意改动系统设置。尚未确定的问题，可记录 AE 版本和错误信息后反馈。

## 看不到粒子

先检查目标图层与效果，再检查 Emitter → Particle → Output 是否完整；接着确认观察时间、发射设置、寿命、大小、透明度和画面位置。单个节点被选中不代表该分支已经接到输出。

先用基本外观确认可见，再恢复纹理、模型或复杂运动，通常更容易区分连接问题与素材问题。

## 数值变了，画面却没变化

确认是否改到了目标节点，节点是否参与输出，以及改的是合成时间动画还是生命曲线。某些模式需要有效来源；Turbulence 的 Noise 模式当前也不会单独改变渲染。

## 预设或素材不一致

确认是否应用到了正确目标，采用了添加还是替换，以及纹理或模型来源是否齐全。不要为排查反复覆盖唯一的预设和工程文件。

## 仍无法确定时

记录出现问题前的操作、完整提示和最小复现方式，见[反馈问题](/help/feedback)。不要把删除缓存、重装插件或修复工程作为每个问题的默认第一步。
