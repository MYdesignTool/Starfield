# 界面总览

Starfield 的使用围绕节点画布、AE 效果控件和预设面板展开。它们分别帮助你组织、调整和复用一个粒子系统。

## 画布负责结构

在[节点画布](/interface/graph-panel)中，你关注有哪些节点、谁连接到谁，以及哪些分支最终到达 Output。节点位置便于阅读，连接关系决定流程。

## 效果控件负责数值与动画

节点的参数通过 [AE 效果控件](/interface/effect-controls)编辑。调整前确认选中的图层和节点；多个同类节点可能拥有相似控件，名称相近不代表它们是同一个对象。

## 预设面板负责复用

[预设面板](/interface/preset-panel)用于浏览已有设置，并保存或导入自己的预设。应用预设会改变目标粒子系统；先确认目标，再决定保留原节点还是替换。

## 预览结果在合成中观察

画布显示的是流程，不是最终渲染。调整后要回到合成查看画面，并在不同时间点检查结果。一个节点被选中，只表示当前编辑对象；是否影响画面还取决于它的连接和设置。
