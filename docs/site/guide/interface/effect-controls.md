# AE 效果控件

Starfield 使用 AE 效果控件编辑节点参数。节点画布负责连接；大小、颜色、发射设置等具体数值在这里调整。

## 先确认编辑对象

同一图层可以有多个节点。调整前，确认当前图层和要编辑的节点，尤其是在多个 Particle 或 Force 并存时。改动另一个同名节点，是“数值变了但画面没变化”的常见排查方向。

## 参数按职责分布

Emitter 关注发射，Particle 关注寿命和外观，Force 关注力的影响；整体输出设置与单个节点的设置也有区别。找某个参数时，先判断它应该改变流程中的哪一部分。

## 动画属性

在 AE 中，可动画的属性通常带有秒表入口。并不是所有下拉选择、素材选择或结构操作都适合做成关键帧。先在固定设置下确认效果，再对明确支持动画的属性进行编辑。

## 曲线与渐变

随生命变化的曲线描述单个粒子从出生到结束的变化；它与 AE 时间线上的关键帧不是同一条时间轴。二者可以共同影响画面，详见[关键帧与动画](/looks/animation)。具体控件操作将在后续补充。
