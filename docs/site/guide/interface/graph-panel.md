# 节点画布面板

节点画布把粒子系统的组成放在同一个视图中，适合建立流程、整理分支和寻找编辑对象。

## 节点、端口与连线

节点代表一种职责，端口表示它能接收或提供什么，连线表示两者之间的关系。发射来源、粒子流程和模型几何并不是同一种输入，不能只看线条的位置就判断能否连接。

阅读一个系统时，可以先找到 Output，再沿连接回看哪些 Particle 和 Emitter 参与了输出。新建节点若仍孤立在画布上，不会因为出现在视图里就参与画面。

## 布局与效果分开理解

把节点摆得更整齐有助于理解，但不是在移动合成中的粒子。需要改变画面位置、范围或朝向时，应查看相应节点的参数。

## 视图导航

平移、缩放、适应视图和缩略图用于寻找节点，不改变粒子参数。节点较多时，可以把来源、外观和运动按流程排列，让分支的去向更容易辨认。

更多基础操作见[移动与整理画布](/canvas/navigation)和[连接与断开](/canvas/connections)。具体工具位置和手势会随界面更新补充。
