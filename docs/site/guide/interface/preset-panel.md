# 预设面板

预设面板帮助你浏览和复用粒子设置。预设包含一套节点关系与设置，不是已经渲染完成的视频。

## 浏览与理解

分类和搜索用于寻找合适的起点。预览图帮助辨认预设，但不能代替把预设应用到自己的合成中观察；合成环境、时间和引用素材都可能影响画面。

## 确认目标

应用前先确认当前目标图层和粒子系统。浏览预设与修改工程是不同的动作，不要把选中一张预览图理解为已经应用成功。

## 添加和替换

添加用于在保留当前节点的基础上引入预设；替换用于改用预设的节点设置。替换可能移除原有结构，操作前应保存工程或保留副本。是否采用预设的输出设置，也应在应用时留意。

## 保存和交换

可以围绕一个创作目标保存自己的设置。与别人交换预设时，还需要说明它依赖哪些纹理、模型或合成内容，不能把预设当成完整工程的替代品。
