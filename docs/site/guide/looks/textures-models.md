# 纹理与模型

纹理和模型都能丰富粒子外观，但它们提供的内容不同。准备素材前，先判断自己需要平面图像还是几何形体。

## 纹理提供图像内容

纹理使用图层图像作为粒子表现的一部分。图像中的透明区域会影响可见轮廓；选择了纹理却看不到粒子时，应检查来源、透明度和时间，而不只是发射量。

纹理颜色、粒子颜色和透明度如何组合，需要结合具体模式理解，不能默认任何贴图都会完全保留原图外观。

## 模型提供几何形体

Model 输出几何，可以直接进入 Output，或用于 Particle 的模型输入。需要表面属性时，可在几何路径中加入 Material。模型输入和发射输入不能混用。

## 保留素材及上下文

纹理图层可能依赖合成中的其他内容，模型也有自己的来源。保存预设不表示所有依赖都已经收集；交换设置时说明需要哪些素材，并保留对应文件。

## 暂缓的操作细节

素材选择、导入格式、时间采样、前后表面和比例选项会在专门的操作说明中补充。先用一个容易辨认的素材测试，再把复杂素材带入正式工程。
