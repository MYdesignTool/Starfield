# 推荐学习路线

不用按目录从头读到尾。先选择你当前最想完成的事，再逐步补充相关知识。

## 第一次使用粒子工具

先读[认识 Starfield](/start/welcome)，理解发射、粒子和输出的关系；再读[第一个粒子系统](/start/first-system)，用最简单的结构建立直觉。接下来认识[粒子外观](/looks/appearance)，最后再加入运动。

## 已熟悉 After Effects

先看[界面总览](/interface/overview)和[AE 效果控件](/interface/effect-controls)。重点区分画布连接与参数编辑，以及合成时间上的关键帧和单个粒子生命中的变化。

## 从某种效果出发

要理解粒子从哪里出现，先看 Emitter；要调整样子与寿命，看 Particle；要控制运动，看 Force、Transform、Motion 和 Turbulence；要使用几何体，看 Model 和 Material。

这些节点的用途不同，不需要为了让效果丰富而把它们全部串在一起。先明确想改变的是来源、外观还是运动，通常能更快找到合适入口。

## 从预设开始

可以先读[浏览与应用](/presets/apply)。应用后先识别主要节点，观察连接，再调整少量参数。预设适合作为学习和创作起点；在大幅修改前保留原始设置，方便比较。
