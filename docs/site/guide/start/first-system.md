# 第一个粒子系统

这一页先介绍构建思路。面板入口、按钮位置和逐步截图会在操作流程稳定后补充。

## 确认最小粒子链

先认识 **Emitter → Particle → Output** 三个角色：Emitter 提供发射来源，Particle 定义粒子生命与外观，Output 接收最终结果。Force 不是产生粒子的必要条件，不必一开始就加入。

如果画布已经有了基础节点，先检查它们的连接，不必重复创建。孤立的节点可以用于暂存想法，但没有接入有效输出的部分不会自动显示在画面中。

## 先调整能直接观察的内容

从发射数量的节奏、粒子寿命、大小、颜色和透明度开始。每次只调整一个方面，在几个时间点比较结果。粒子太小、太透明或处于画面之外，都可能让一个已经连接的系统看起来像没有工作。

具体参数在 AE 效果控件中修改，不是在画布节点内部填写。

## 再增加运动

看清基础粒子后，再考虑运动。想改变发射时的速度，先看 Emitter；想加入重力或风，了解 Force；想整体移动、旋转或改变分布，了解 Transform。

## 最后加入动画与复用

先得到一个静态设置下可理解的结果，再添加关键帧。满意后保存 AE 工程；需要复用节点设置时，再考虑保存预设。
