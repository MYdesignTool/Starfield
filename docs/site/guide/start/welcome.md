# 认识 Starfield

Starfield 是在 After Effects 中使用的节点式粒子工具。你用节点组织粒子如何产生、呈现和运动，再在 AE 中预览与输出画面。

## 三个主要部分

| 在哪里 | 主要做什么 |
| --- | --- |
| 节点画布 | 添加节点，组织连接，查看效果的组成 |
| AE 效果控件 | 调整节点参数，编辑可动画属性、曲线与渐变 |
| 预设面板 | 浏览现成设置，保存和复用自己的想法 |

画布中的线表示节点之间的关系，不是粒子在合成中的运动轨迹。拖动画布上的节点主要是在整理布局；改变粒子的发射位置，应调整节点参数。

## 从最小结构开始

**Emitter → Particle → Output** 是理解粒子流程的起点：Emitter 决定发射，Particle 决定粒子的生命和外观，Output 汇集结果。想让运动更丰富，再加入 Force、Transform 等节点。

节点不必全部用上。先确认一个简单系统能显示，再逐步增加变化，更容易知道是哪一处调整改变了画面。

## 网站演示与实际创作

官网的节点画布用于体验连接和布局，不会生成粒子。实际效果需要在 AE 中使用插件预览。官网首页的粒子图片也是概念主视觉，不是可直接套用的效果预设。
