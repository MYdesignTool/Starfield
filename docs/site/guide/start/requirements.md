# 使用前的准备

开始前，先准备一个便于观察和保存的 AE 工程。第一次尝试时，简单的场景比复杂工程更容易理解。

## 使用环境

当前 Starfield 的开发与使用说明面向 **Windows x64 和 After Effects 2023**。其他 AE 版本、操作系统和设备组合尚未在这里提供使用保证。请以实际发布版本的说明为准，不要根据界面能打开就判断所有功能都可用。

安装包与更新以项目 Releases 中实际提供的内容为准。入口已经开放，但这不表示一定已有可下载的正式版本。具体安装步骤将在发布流程确定后补充，参见[安装与更新](/start/installation)。

## 需要了解的 AE 概念

你不需要编程经验，但应能区分工程、合成、图层和效果，知道如何移动时间指示器，以及在哪里查看效果控件。制作动画时，还需要了解关键帧的基本作用。

节点画布、预设面板和 AE 效果控件承担不同任务；找不到某项设置时，先确认自己正在使用哪一个界面。

## 准备一个测试工程

建议从一个结构简单的合成开始，先观察基本粒子，再加入其他效果、素材或动画。改变设置后检查多个时间点，避免只看恰好没有粒子的起始帧。

## 保留原始工程和素材

对已有作品做较大修改前，保留一份工程副本。若使用纹理图层或外部模型，也要保留这些素材；保存一个预设不等于打包了整个 AE 工程。
