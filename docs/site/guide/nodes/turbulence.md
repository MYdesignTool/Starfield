# Turbulence · 扰动

Turbulence 用噪声为粒子增加变化。它适合在较规则的基础运动上加入不完全一致的偏移，而不是替代发射来源。

## 先区分变化范围与变化强度

噪声的空间分布、幅度和随时间变化的方式是不同方面。改变空间尺度，不应简单理解为让所有粒子一起移动得更远。先固定其他设置，只比较一项变化，更容易建立直觉。

## 当前模式范围

当前提供 Normal、Axis 和 One Side 入口。Spherical 等其他模式不属于本页已经开放的功能说明。各模式的方向、影响范围和具体参数操作将在后续分开说明。

## All 与 Noise 的区别

当前实现中，All 会把扰动作用到粒子的表现；Noise 保留采样噪声供后续使用，本身不会单独产生可见的渲染变化。因此选了 Noise 却没有立即改变画面时，不能直接判断节点失效。

## 从可见的基本流程开始

先确认上游粒子存在、节点已接入输出，再观察扰动。将生命变化、随机变化和多个运动节点一起开启，会让判断来源更困难。
