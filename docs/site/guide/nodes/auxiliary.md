# Auxiliary · 辅助发射

Auxiliary 用于以已有粒子为来源进行辅助发射。可以把它理解为从父粒子产生子粒子的入口，而不是另一个独立空间形状的普通 Emitter。

> 本页已建立章节结构。操作步骤、参数说明与示例将在后续版本中完善。

## 节点用途

已有粒子提供父来源，辅助发射再形成子粒子流程。父粒子与子粒子的外观、生命和运动需要分开理解；不要把辅助发射直接等同于任意层数的递归繁殖。

普通 Emitter 与 Auxiliary 的输入含义不同，不能仅凭名称相近就互换使用。
