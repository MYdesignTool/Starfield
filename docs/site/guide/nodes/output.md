# Output · 输出

Output 是图中的最终汇集点。它决定哪些已连接的流程参与最终结果，也是理解整个系统时值得先找到的节点。

## 连到输出才有意义

有些节点会先被放在画布上，供后续连接。它们的存在不意味着已经影响画面。查看效果时，先沿着连接确认目标分支确实通向 Output。

## 全局上限与发射量

Max Particles 是全系统的粒子数量上限，不是每个发射器都能独占的一份数量。达到上限后，继续增加发射设置不一定按预期增加可见数量。

粒子寿命和观察时间也会影响同时存在的粒子数，因而应和发射设置一起理解。

## 输出设置与单个节点

整体预览、时间和渲染相关设置，与 Particle 的外观、Emitter 的发射是不同层级。应用预设时，也要留意是否一并采用预设的输出设置。

## Output 不等于导出文件

连接到 Output 表示粒子结果进入插件输出，并不是已经在磁盘生成了视频。最终画面仍在 AE 合成中预览，并使用 AE 的输出流程制作文件。
