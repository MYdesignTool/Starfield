# Motion · 运动

Motion 提供围绕运动形式和方向组织效果的入口。它与 Force 侧重力的影响不同，应先按想要的运动目标选择。

## 运动意图

当前可见的运动类型包括 Circle、Light Path 和 Look At。可以分别把它们作为环绕运动、由灯光路径引导，以及朝向目标的阅读入口。具体行为应结合各模式的参数与合成中的引用对象理解。

## 先检查来源，再调整运动

需要灯光或路径来源的模式，不能只添加节点就期待出现对应运动。来源对象、名称筛选和轨迹条件都会影响可用输入。没有符合条件的来源时，不要仅靠增大运动参数排查。

## 运动与外观朝向

位置移动与朝向变化是两件事。圆形粒子不容易显示朝向差别，判断朝向时应选择便于辨认方向的外观，避免把“看不出朝向”直接理解为位置没有变化。
