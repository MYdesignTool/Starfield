# Transform · 变换

Transform 用来改变进入该节点的粒子在空间中的布局和表现。它与在画布上移动节点不同，也不等同于调整整个 AE 图层的变换。

## 位置、旋转与锚点

位置用于移动粒子布局，旋转围绕锚点进行。锚点的位置会影响旋转与缩放的中心。需要整体挪动一个流程时，可以先看 Transform，而不是逐一改动所有发射来源。

## 分布缩放与粒子大小

系统的 Scale 与 Particles Scale 应分别理解：前者关注粒子中心之间的空间分布，后者关注粒子自身的大小。想把一团粒子拉开，同时保持每个粒子的视觉大小时，要留意这一区别。

## 透明度与已有外观

Particles Opacity 用于进一步调整该流程的粒子透明度。它会和 Particle 原有透明度、生命变化一起影响结果；如果上游已经完全透明，后续调整不能凭空恢复被隐藏的外观信息。

## 节点顺序值得保留

变换与其他运动节点组合时，顺序可能影响结果。比较前后差别时，先保留原图，再只调整一个连接或一组设置。继承图层运动的选择方式、坐标与具体操作后续补充。
