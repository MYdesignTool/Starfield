# Particle · 粒子

Particle 定义一组粒子的生命与外观。Emitter 决定粒子如何出生，Particle 决定它们出生后是什么样、能存在多久。

## 生命与年龄

寿命描述一个粒子从出生到结束的持续时间。粒子年龄从各自的出生时刻开始计算，因此同一合成帧里可以同时有刚出生、处于中段和即将结束的粒子。

## 基础外观与随生命变化

大小、透明度和颜色是观察外观的主要入口。基础大小与 Size Over Life 曲线承担不同任务：基础值给出尺度，曲线描述生命过程中相对于基础值的变化。透明度也要区分基础值和随生命变化。

例如把基础大小改大，不等于改写了一条生命曲线；让生命末段变小，也不等于把所有时刻的基础大小同时缩小。

## 输入与后续节点

Particle 接收直接的发射来源。使用模型外观时，还有用途不同的模型输入，不能把几何来源接成发射来源。粒子输出可交给 Force、Transform 等处理，或直接进入 Output。

## 观察时先简后繁

先确认单一颜色、大小和寿命下的结果，再叠加随机变化、纹理或动画。这样更容易判断最终变化来自基础设置、生命曲线还是后续节点。
