# 在线上插入节点

在线上插入节点，是把已有的 A → B 关系改为 A → 新节点 → B。它适合在已经工作的流程中增加一种处理。

## 先判断插入位置

例如在 Particle 与 Output 之间加入 Force，可以让该粒子流程受到力的影响。选择哪一条分支，决定你希望修改哪一部分；不要只根据画布上空白的位置判断。

## 输入和输出必须相容

新节点需要同时能接收原上游内容、又能交给原下游。模型路径与粒子路径不同，不能为了插入成功而接到用途不相符的端口。

## 插入后检查两端

观察原连线是否已被替换，新节点两端是否完整连接。若有多条相邻线，应确认插入的是目标线，而不是另一条分支。

## 比较前后变化

先用温和的设置观察差别。节点加入后未必立刻产生明显变化，仍需检查它的参数。具体拖入位置、提示样式和取消方式将在操作说明中补充。
