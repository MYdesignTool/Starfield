# 撤销与保存

编辑节点、调整参数和整理布局都属于创作过程。重要修改前先保存，可以让比较和返回更从容。

## 撤销不是保存

撤销用于返回之前的编辑状态；保存用于保留工程。不要把撤销历史当成工程备份，也不要依赖关闭后仍能找回全部历史。

## 保存工程与保存预设

AE 工程保存的是项目上下文，包括合成、图层和效果。Starfield 预设用于复用节点设置，不等同于完整工程，更不能代替引用的素材文件。

## 结构变化后检查

删除、复制、重接分支或替换预设后，检查连接、节点参数和几个时间点的结果，再保存。若只是想试验新方案，保留一份工程副本更容易比较。

## 重新打开时

除了看节点是否存在，也要确认素材引用是否可用。若结果与保存前不同，先检查使用的插件版本和素材，再记录问题现象。

具体撤销入口及跨面板的操作说明待界面稳定后补充。相关内容：[保存自己的预设](/presets/save) · [反馈问题](/help/feedback)。
