# 移动与整理画布

画布导航帮助你看清系统，不会改变合成中的相机或粒子位置。

## 移动节点与移动粒子

拖动节点是在整理图的布局。粒子从哪里出现、分布多大、朝哪里运动，要通过对应参数调整。不要把画布坐标当成合成坐标。

## 平移、缩放和适应视图

这些操作改变你看到的画布范围。缩小画布不会把粒子渲染得更小，放大画布也不会提高输出分辨率。找不到节点时，先考虑是否移到了当前视图之外。

## 用结构帮助阅读

可以把发射来源放在流程开始处，外观与运动按关系排列，让汇入 Output 的路径保持清楚。共享节点要留出空间，避免让交叉的线掩盖实际连接。

## 缩略图的用途

缩略图帮助定位整个图中的区域；它不是粒子预览窗口。最终效果仍应在 AE 合成中检查。具体导航手势和布局工具会随界面更新补充。
