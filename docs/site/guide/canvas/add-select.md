# 添加与选择节点

添加节点是在流程中引入一种职责，选择节点则是在已有系统中确定编辑对象。二者不会自动完成所有连接。

## 按目标选择类型

需要发射来源时考虑 Emitter，需要调整粒子外观时查看 Particle；运动、变换、模型和材质分别有自己的节点。不要仅因为名称相近就互相替代。

## 选择与多选

单个选择便于定位参数，多选便于整理一组节点。选择状态不是启用开关，也不表示只有选中的节点会显示；实际输出由有效连接和参数决定。

## 复制后的检查

复制有助于比较不同设置。复制后应确认新增节点、它们的连接和参数归属，不要仅凭画布位置认为副本已经替换了原分支。

## 删除前先看关系

一个节点可能被多个分支使用。删除前先看它连接到哪里，避免同时影响其他部分。Output 是系统的输出端，不能把它当成普通装饰节点随意处理。

工具按钮、选择手势和复制快捷键将在操作界面稳定后补充。继续阅读：[连接与断开](/canvas/connections)。
