# 导入与导出

交换预设时，需要区分节点设置文件和它依赖的创作素材。两者一起说明，才能减少“导入成功但效果不同”的情况。

## 预设携带什么

预设用于保存和传递粒子节点设置。它不是已渲染画面，也不是完整 AE 工程；不要默认它已经包含合成中的所有图层、纹理或模型依赖。

## 分享前准备什么

记录预设用途、使用的插件版本，以及需要另行提供的素材。保留原始预设和工程副本，再进行交换；重要的备份不要只留在一个工作目录里。

## 导入不等于应用

把设置加入预设库，与把它应用到某个粒子系统，是不同动作。导入后先检查信息，再确认目标，并决定添加或替换。应用方式见[浏览与应用](/presets/apply)。

## 文件操作说明

导入入口、保存当前设置与导出备份的具体步骤会随文件工作流确认后补充；本页暂不指定固定扩展名、目录或按钮位置。遇到版本不匹配提示时，保留文件并记录提示，不要反复覆盖唯一副本。
