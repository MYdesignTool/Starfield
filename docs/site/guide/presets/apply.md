# 浏览与应用

预设是一套可以复用的节点设置。它帮助你从已有结构出发，但应用后仍应在自己的合成中观察结果。

## 先确认目标

确认你希望修改的图层和粒子系统。浏览时选中的预设与工程中的目标是两件事；应用前留意面板显示的目标，避免把设置送到另一个系统。

## 添加与替换

添加用于保留当前节点并引入预设内容；替换会改用预设的节点结构。已有作品上尝试替换前，应先保存工程或保留副本。

不要把“添加”理解为最终画面只会额外叠一段视频：新节点仍然进入同一粒子系统，整体结果还受连接和输出设置影响。

## 留意输出设置

应用时可以涉及预设的渲染设置。比较两个预设时，确认是否同时改变了全局输出，否则差异未必只来自新增节点。

## 应用后先阅读结构

找到 Emitter、Particle 和 Output，确认主要运动节点，再逐步调整。预览图不能代替实际合成预览；素材、时间与版本差异也可能影响结果。
