# 保存自己的预设

当一组节点能表达一个可复用的想法时，可以把它整理为预设。预设适合保存效果结构，不是用来替代整个 AE 工程。

## 保存前先整理

确认节点关系完整，去掉不需要带给下一次创作的试验部分，并检查效果在几个时间点的表现。为了便于复用，尽量让预设的用途清晰，例如一套发射布局或一种运动组合。

## 用名称表达用途

名称可以说明视觉特征或创作目的，说明文字则记录适用场景、需要的素材，以及使用时首先应检查什么。不要仅用无法辨认的临时编号区分多个相似版本。

## 预设与工程备份

保存预设不意味着已经保存了完整合成、所有动画或外部依赖。仍应单独保存工程，并保留模型、纹理等素材。需要完整复现时，先确认这些内容可用。

## 复用前进行检查

在另一个工程中使用时，先确认目标和依赖，再调整到新的场景。版本改变后，不应仅凭预设文件能被选中就认定所有设置都已正确恢复。
