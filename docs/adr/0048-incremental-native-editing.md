## Proposed boundary

A shared resident native edit service should receive bounded deltas using stable identities and a base generation. Ordinary structure edits should capture only changed author metadata and preserve sources until the new graph has actually been published. Keep active-source validity, a single authoritative publication acknowledgement, and AE dependency tracking. Avoid repeated full manifests/snapshots, full-effect duplication and the Model asset protocol for ordinary edits. Keep the complete resource transaction for operations that really need asset or animation restoration.

Before publication, restore only this operation's metadata on failure, composing with the existing publisher's checked Arb/alias rollback. After confirmed publication, treat physical deletion/final refresh as cleanup: report committed state and cleanup errors accurately. Zero backups do not provide full restoration of already deleted animated effects. A user AE Undo group is useful, but automatic AEGP_DoCommand(16) is rejected as a rollback mechanism: the public SDK has no token selecting this edit's undo group.

Clear/Collection handling can improve known UI entry points but must not be the lifetime guarantee. Whole-effect selection can use STREAMREF; parameter/keyframe/mixed selection and script/other-plugin removal must not be misclaimed as covered. A separate, explicit generation/lifetime contract is required to cancel old derived reads and reconcile known source removal without interpreting unknown corruption or invalid live values as deletion. Do not simply skip finite handoff or introduce zero/stale fallback.

Known ECW Clear may call the same bounded native executor synchronously in the AEGP CommandHook; the public SDK does not require adding another idle queue there, and the existing native commit/repair handlers already write through that entry. Preflight must identify a whole owned effect set before consuming the command; once an owned edit is consumed, busy/failure must not fall through into AE default deletion. Keep UI-thread/non-reentrancy checks, exclusion/epoch and local references; do not pump messages, wait for assets, execute JSX or open modal dialogs inside the executor. WebView callbacks continue to queue for safe UI idle. This is a proposed simplification, not host-qualified Clear ordering or coverage.

Replace global source-removal invalidation with affected-source/slot dependency analysis only after controlled real-entry tests establish which dependencies survive actual parade changes. Preserve AE animation/time dependency semantics; a native shared interface alone does not establish them. Selection and layout should not automatically dirty simulation, subject to existing save/Undo semantics.

## Qualification and scope

This proposal introduces no public IDs, match names, graph/sequence schema, Core ABI or Render.hpp change. Any implementation that needs such a change must first add its migration contract. The first implementation is native125/panel112, frozen and deployed 2026-10-30 with 124/111 rollback. It migrates node deletion only; add/connect/layout and complex resource edits retain their existing routes. The deployment receipt and independent v4 review live under artifacts/stb-17-20261029; they do not close AE qualification.

Implementation must first specify operation-specific read/write/rollback sets and SDK-call budgets, test all node types/Auxiliary, multi-selection, missing sources and pre/post-publication failures through actual production entry points, and receive a fresh independent repair review. Current design review rejected automatic Undo and incomplete Clear interception. AE2023 deletion, Undo/reopen and input-to-frame latency remain owner qualification gates; compilation or fake SDK timings do not close them.

## First candidate: deletion only

The panel sends a bounded target/revision/CRC/project-path/UUID delta through the existing deferred WebView queue. The Host checks the saved project path before resolving the target. It scans author metadata once, stores changed connection banks, marks removed sources guard3 while alive, prunes affected links and invokes the existing publisher once. The publisher's positive ACK is the commit point; no duplicate success-time scalar confirmation is required. Then the Host deletes originals in descending order, reacquiring scoped refs, refreshes final bindings and releases its guard. No full effect backup or Model session/upload/poll/release occurs. One read-only panel snapshot follows for display.

The existing publisher's destructor rollback does not certify every restored alias. Consequently a failed generic publication remains guarded after author metadata compensation; do not advertise complete precommit rollback or clear that guard from an unchanged revision alone. Failures before the publisher is called may release their owned guard only after metadata restoration. A missing ACK is explicitly an unknown outcome unless saved publication proves commitment; it is never retried automatically. Positive ACK followed by any later failure stays committed with a cleanup error. User Undo remains the recovery group; existing damaged author/derived states use explicit Diagnostics, never silent repair.

ECW selection is read only after acquiring exclusion; busy Clear is consumed before SDK queries. Resolve whole EFFECT/STREAMREF items with public parent/root/unique-stream-ID checks, dispose collection-owned references before structural changes. Execution additionally requires a positively observed current native child focus matching an EFFECT menu observation, excluding all WebView trees. A remembered EFFECT type and root-only focus do not authorize a residual ECW selection. For an ambiguous but identified owned set, capture/drop without mutation. This is limited UI coverage: mixed selection, script/other-plug-in deletion and general external-generation reconciliation remain open.

The initial saved-path check plus existing stable graph identities reduces queued cross-project confusion. Unsaved projects have an empty path; a new global project-generation contract is not claimed. Public IDs/schemas/Core ABI remain unchanged.

Native Edit/RichEdit/ComboBox focus, including child ancestry, leaves Clear to the native text control before selection capture or the effect-delete repeat latch. This covers known standard text windows; it is not a claim to identify all custom AE text widgets or qualify real host menu routing.

## STB19: application Clear lifecycle candidate (126/114)

A deleted target has no surviving graph to reconcile. Only a same-base census losing a subset of captured selected native UUIDs, with survivor kind/connection records unchanged and no new source/effect-count surprises, permits pruning affected links and one publication. Successful publication retires old aliases, refreshes final dependencies and releases the guard before closing Undo/epoch.
