# UX-13：编辑图、渲染图与快速操作

Owner要求删除/摘出节点后桥接上下游；所有现有节点输入输出可自由连线，语义错误保留并显示黄色三角与悬停说明。当前源候选为 native128/panel117，安装与最终审校状态以 current-state.md 为准。保持单击打开 AE Effect Controls；未启动、关闭或操作 AE/工程，不从离线结果推断 AE 吞吐。

## 数据与执行边界

既有作者连接 bank 继续存目标 UUID、edge UUID，最多63个作者节点、每节点四条输出，不新增公开参数、ID、schema 或 Core C ABI。Model、普通 Emitter 的既有输入也显示出来。端口由既有节点类型推导，Model/Material→Particle固定 model3；不能把未存储的任意端口选择伪装成已持久化。

作者图由 native manifest 恢复，保留错误边、环和自连接。Core 的只读 topology preflight 共用实际 stream、Motion、Transform、Model 分组规划器，并检查 Auxiliary 父图前缀；不生成粒子、不采样历史、不读取宿主资源。动态资源仍在 PreRender 捕获；非法数值、布局/身份损坏、容量、取消和预算失败仍是硬错误。Auxiliary Life Start > End 是数值错误，不靠剪边隐藏。

完整语义合法图一次检查后原样保留，包括历史 Material→Model 附着。错误图先检查无边时所有节点，再按 edge UUID 依次接纳非 Output 边、Output 边，最终复查。它是确定的安全子集，不保证最大子集；警告记录接纳该边时的冲突。此前静态求值中不执行的错误停放边现在也警告，但作者边仍保留。渲染器不接收悬空源或错误执行拓扑，不增加 Emitter/Auxiliary 直接输出外观语义。

警告存于新私有 optional record 0x8010（有界版本/数量/端点/edge/code/ASCII静态详情），保存、Undo、重开可恢复。127能忽略该记录读取合法渲染图，但不支持编辑含错误作者连线的新草稿；回退前应撤销或修好这些草稿。完整 native/Core/panel 配对部署，公开 C ABI 不变。

## 提交与删除

面板本地预览有界队列：最多64条意图、每批最多32条，一个宿主写入；未提交意图合并，ACK后只重放尚未提交者，ID稳定。复制资源节点保留单独批次与完整资源事务。连接、断开、桥接、摘出及只删除已有作者的批次走 native patch；新增/参数/资源变更保留既有受控发布器。源参数由现有127状态证明路径处理，不建立第二套面板数值编辑器。

Native patch 用项目路径、目标身份、revision/CRC、全作者 census 和各行旧连接 CAS 后才写；只写变化行，等数量替换也写，增长时先捕获旧的非活动尾部，失败按 max(old,new) 精确恢复。旧依赖交接、guard、原子epoch和正发布ACK保持。物理删除前源仍存活，删除后最终强制绑定刷新保持127保护；仅改线无需物理移除，因此不做该最终刷新。未知结果不自动重发或自动 Undo。

第二轮独立复核确认一个新回归：排队期间已确认图层高度改变，尚未提交的 Emitter/Turbulence 默认值仍沿用准入时的高度。修复让每次预览重放与批次构造都使用该批已确认 receipt 的尺寸，保留已分配 UUID；覆盖 Emitter Speed 与 Turbulence 两个长度默认字段。复制同时捕获用户操作时的画布来源位置，避免尚未保存的移动导致复制节点落在旧位置。已在宿主执行中的完整事务仍遵循原有 gateway 准入合同，不把这项修复宣称为新的宿主几何 CAS 协议。

额外持续混合压力测试暴露普通复制也被当作资源屏障，导致不必要积压。屏障现只用于实际非零Model资源UUID的复制：按顺序构造批次光标，普通节点与默认Cube可合批；带资源的Model复制及其后续复制必须等待对应来源的已确认资产。单宿主写入、32条批次与64条准入上限不变。

删除/摘出按被选节点集合的边界桥接，跨选择链寻找存活下游，去重已有端点，不合成自桥。摘出保留节点数值、身份和最终位置。类型不合的桥接也保留为警告。四条输出仍是原生存档硬上限；面板在接受意图前拒绝超限。效果控件 Clear 保留 AE 实际选中目标和旧活动绑定数值捕获；对可能的删除子集先保守检查桥接容量，拒绝发生在物理 Clear 前。

布局仍本地拖动、安静期合并坐标保存，不进入图/绑定发布。结构 ACK 为布局队列更新已确认成员，保留拖动暂停和未保存位置；不取消已有布局写入。拖动期间的 ACK 仅暂存预览，错误/换目标后不可由旧拖动重新开放编辑。晃动需屏幕每腿12px、700ms内四次反向，只对单节点非复制拖动在 pointerup 摘出，取消不提交；优先于自动插线。

## 诊断与失败

SF-B101等标识绑定类别，SF-G101..110标识连接问题，SF-T标识提交/回执/冲突；AE516作为宿主状态，继续返回合法SDK错误值。弹窗含节点 UUID/参数/组件/stream/native build；面板先显示简明说明，完整原始错误与trace折叠在详情。黄三角使用文本/title/ARIA，不执行错误中的HTML。

私有只读 selector 使用真实 PF handle utilities 与 AEGP 保存流，不读取 generic params[]，核对 revision/CRC 与保存ARB。失败通过状态返回，selector本身返回 NONE，避免背景诊断弹 AE 对话框。显示只匹配当前目标/项目/revision/CRC/页面与目标代际；错误 Output 边只标相关上游，不污染无关分支。读不到时显示 Warnings unavailable。

相对设计v2的明确调整：尚未增加跨模块诊断事件环；初次采用/Refresh/已完成的一轮编辑队列后发一个只读诊断请求，不阻塞下一次编辑，不重扫作者参数，不把它当提交确认。相同 receipt 去重；连续未完成操作不会逐条查询。该额外读的实际 AE 成本仍需计时；不声称所有通信已消除。Native请求30秒未回应会停止准入并报告未知结果，释放回调/计时器，晚回执不自动恢复或重试；保留普通脚本既有8秒等待，不用它误判Owner已报告的5–10秒原生操作。
