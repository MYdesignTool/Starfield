# PERF-16 图层选择发现与加载

Owner报告119切换图层刷新慢并似乎阻断选择。静态路径确认：空闲轮询退到2秒；getPanelPulse仍读取完整renderer记录/帧状态；变化后完整作者读取，随后立即发原生诊断。它们都占用AE脚本/UI调度。WebPanelHost普通evalScript不设置焦点，只有显式节点点击的KeepGraphFocus路径才在无后续用户输入条件下恢复图焦点；不能把体感停顿直接归因于普通刷新抢焦点。没有操作真实AE，耗时原因仍需Owner现场验证。

panel120新增selectionOnly的getPanelPulse早返回路径：解析有效选择或仍有效上一目标，返回token/projectScope身份；不读renderer参数、图回执、节点、曲线、资源或帧状态，不修改选择/Undo/效果。使用官方只读CompItem.selectedLayers零基数组，老夹具/能力缺失时保留枚举后备。多选若已有明确的可用画布则保留该目标，无旧目标仍拒绝猜测。没有新增工程全局效果扫描或持久缓存。

完成式轮询每200ms做一次轻探测，120ms稳定门意味着通常连续两次同一选择才完整加载。连续B/C/D只为最后稳定D读取图；最多一个选择/状态/完整读取在途，忙时保持短的本地定时检查，不在完成后额外退2秒。关闭自动刷新、页面隐藏、交互/编辑和布局待处理时不发探测。窗口focus只唤醒轻探测，不同步完整读；暂停时仍保留119的显式旧目标focus读取。UI间隔不是AE端到端毫秒承诺。

稳定目标的普通状态仍每2秒最多一次，15秒完整审计仍在；完整加载采纳snapshot.panelStamp，避免首次状态检查再把同一张图加载一遍。保留scope/旧回执/暂停竞态检查和显式画布目标。没有把缓存图当成新作者确认，也不跳过编辑所需的完整快照、初始化/修复或事务保护。

选择加载后的原生诊断延后800ms安静期；新选择立即取消旧定时，繁忙时安全延后，目标/epoch/revision/CRC/scope再次匹配才读。结构编辑自身的即时诊断保持。局部派生黄色警告仍本地显示，已持久化红色详情可能晚800ms出现。这减少连续切换中的原生UI排他查询，原生诊断入口本身不改。

实际JSX夹具在5万图层的合成中验证selectedLayers路径不调用comp.layer、不读renderer/作者值、不写宿主。实际panel压力用例验证B/C/D合并、focus合并、慢读取时单在途/200ms检查、旧诊断取消、暂停/隐藏、空目标和状态采样。调用次数不等于真实AE耗时或无卡顿保证；native128、Core ABI9、公开ID/schema和删除/绑定/提交保持。
